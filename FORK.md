# dsh-peak-indicator — локальный форк

Форк [future007s/dsh-peak-indicator](https://github.com/future007s/dsh-peak-indicator) с локализацией и долларовыми суммами.

## Что изменено относительно upstream

### Языки

- **中文 (zh) — без изменений.** Китайский словарь остаётся ровно таким, как в upstream: бейдж, тултип, баланс и отсчёт показывают те же китайские строки (`高峰`/`闲时`, `10 小时 44 分钟` и т. д.).
- **Русский (ru) — добавлен.** Для пространства имён `peakIndicator` регистрируется русский словарь: `⚡ Пик`/`🌙 Вне пика`, тултип с ценами, статусы баланса, `ч`/`мин` в отсчёте, а также русский однострочник пакета в списке «Плагины» (через `locale.resolveText`, только при активной локали `ru`). Для работы русского нужен языковой пакет, регистрирующий локаль `ru` (например, `dsh-locale-russian`); без него активная локаль будет `en`.
- **Остальные языки — без навязывания русского.** Если у языка есть свой словарь для `peakIndicator`, используется он; иначе локаль-сервис идёт по цепочке fallback до английского. Словари регистрируются по одному (zh, en, ru) и терпимо к уже занятой локали, поэтому сторонний языковой пакет не ломает загрузку плагина.

### Валюты

- Все цены, стоимость ходов и баланс — в **USD** (`$`); кошельки CNY (`¥`) остаются fallback'ом, смешанные кошельки не суммируются.
- Чтобы Host-проекция `peakCost` тоже считала в долларах, в `cordis.patch.yml` профиля нужна строка:

```yaml
- id: peak-indicator
  name: "dsh-peak-indicator"
  config:
    currency: USD
```

### Отсчёт

- `formatCountdown` берёт единицы из локали (`unit.hour` / `unit.minute`) вместо захардкоженных китайских. Для `zh` вывод идентичен upstream (`小时`/`分钟`), для `ru` — `ч`/`мин`, для остальных — `h`/`min` или свой словарь.

## Установка из этого форка

```sh
dsh plugin --profile <profile> add github:kesha4/dsh-peak-indicator
```

Затем перезагрузить страницу DSH. Требуется DSH `0.2.1-rc.2` или `0.2.1-rc.5` (профили `web` / `desktop`).

## Сборка и обновление

`lib/client.js` собирается из общих модулей (`lib/pricing.js`, `lib/balance.js`) скриптом `scripts/sync-client-pricing.mjs`. После синхронизации с upstream:

```sh
npm install
npm run build                              # пересобрать общие секции client.js
node scripts/apply-fork-changes.mjs        # вернуть форковые правки браузерной части
npm test                                   # sync-check + 65 тестов
```

Порядок важен: `apply-fork-changes.mjs` идемпотентен, но должен запускаться после `npm run build`.

## Тесты

```sh
npm test
```

- `test/locale.test.mjs` — zh-словарь совпадает с upstream, ru покрывает все ключи, неизвестные языки падают в en, отсчёт для zh/ru/en/ko, толерантная регистрация локалей, перевод однострочника пакета только для ru.
- `test/balance.test.mjs` — баланс в USD/CNY, смешанные кошельки, состояния `no-cny`/`failed`/`signed-out`.
- Остальные тесты — upstream (цены, проекции, совместимость, темы).
