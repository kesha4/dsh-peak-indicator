# dsh-peak-indicator — локальный форк

Форк [future007s/dsh-peak-indicator](https://github.com/future007s/dsh-peak-indicator) с локализацией и долларовыми суммами.

## Что изменено относительно upstream

### Языки

- **中文 (zh) — без изменений.** Китайский словарь остаётся ровно таким, как в upstream: бейдж, тултип, баланс и отсчёт показывают те же китайские строки (`高峰`/`闲时`, `10 小时 44 分钟` и т. д.).
- **Русский (ru) — добавлен.** Для пространства имён `peakIndicator` регистрируется русский словарь: `⚡ Пик`/`🌙 Вне пика`, тултип с ценами, статусы баланса, `ч`/`мин` в отсчёте, а также русский однострочник пакета в списке «Плагины» (через `locale.resolveText`, только при активной локали `ru`). Для работы русского нужен языковой пакет, регистрирующий локаль `ru` (например, `dsh-locale-russian`); без него активная локаль будет `en`.
- **Остальные языки — без навязывания русского.** Если у языка есть свой словарь для `peakIndicator`, используется он; иначе локаль-сервис идёт по цепочке fallback до английского. Словари регистрируются по одному (zh, en, ru) и терпимо к уже занятой локали, поэтому сторонний языковой пакет не ломает загрузку плагина.

### Валюты

- **Баланс: валюта выбирается автоматически по кошельку, где есть деньги** — у большинства аккаунтов пополнен только один кошелёк. Пустой кошелёк в другой валюте больше не перебивает баланс: `0 USD + 500 CNY` → `¥500.50`, `0 CNY + 12 USD` → `$12.34`. Если пополнены оба кошелька, показывается USD; если оба нулевые — валюта, которая в ответе есть, с `0.00`; если кошельков нет вовсе — статус «кошелёк не найден». Смешанные валюты никогда не суммируются.
- **Цены и стоимость ходов тоже выбираются автоматически.** Host регистрирует две проекции: `peakCost` в валюте из профиля (по умолчанию `CNY`) и `peakCostAlt` в противоположной (`USD`). Клиент читает обе и показывает ту, которая совпадает с валютой кошелька из автовыбора баланса; бейдж, тултип и чипы «Ход…» используют одну и ту же проекцию. Строка `currency` в профиле теперь **необязательна** — она задаёт fallback до получения баланса и приоритетную валюту для вошедших без данных о кошельке:

```yaml
- id: peak-indicator
  name: "dsh-peak-indicator"
  config:
    currency: USD
```

### Отсчёт

- `formatCountdown` берёт единицы из локали (`unit.hour` / `unit.minute`) вместо захардкоженных китайских. Для `zh` вывод идентичен upstream (`小时`/`分钟`), для `ru` — `ч`/`мин`, для остальных — `h`/`min` или свой словарь.

### Баланс: переподключение

Поток `account.watch` в бейдже баланса больше не «залипает» в состоянии `Баланс: недоступен`:

- при завершении потока (перезапуск Host, перекомпозиция клиентских плагинов, сетевой сбой) или исключении из `remote.$stream` стор переоткрывает поток с нарастающей паузой 5 → 15 → 30 → 60 с; любое полученное событие сбрасывает паузу к 5 с;
- у стора появился `reconnect()`: бейдж в состоянии `недоступен` больше не `disabled`, клик по нему переподключает поток немедленно;
- в тултип всех трёх словарей добавлена подсказка «нажмите, чтобы переподключиться»;
- остановка плагина и `dispose()` отменяют запланированные попытки.

Причина: DSH-клиент не ретраит терминальные ошибки логического Remote-потока, поэтому после перезапуска Host или HMR-пересборки плагина бейдж оставался недоступным до полной перезагрузки страницы.

Тесты: `test/balance-reconnect.test.mjs` (терминальное завершение, исключение в `$stream`, рост паузы, ручной `reconnect`, отмена при `stop`/`dispose`), плюс проверки кликабельности в `test/balance-badge.test.mjs`.

## Установка из этого форка

```sh
dsh plugin --profile <profile> add github:kesha4/dsh-peak-indicator
```

Затем перезагрузить страницу DSH. Требуется DSH `0.2.1-rc.2` или `0.2.1-rc.5` (профили `web` / `desktop`).

## Сборка и обновление

`lib/client.js` собирается из общих модулей (`lib/pricing.js`, `lib/balance.js`) скриптом `scripts/sync-client-pricing.mjs`. После синхронизации с upstream:

```sh
npm install
npm run build                              # пересобрать общие секции client.js
node scripts/apply-fork-changes.mjs        # вернуть форковые правки браузерной части
npm test                                   # sync-check + 81 тест
```

Порядок важен: `apply-fork-changes.mjs` идемпотентен, но должен запускаться после `npm run build`.

## Тесты

```sh
npm test
```

- `test/cost-currency.test.mjs` — бейдж и чип хода выбирают проекцию по валюте кошелька (USD/CNY/неизвестна) и не смешивают валюты между поверхностями.
- `test/projection-alt.test.mjs` — Host регистрирует `peakCost` + `peakCostAlt`, явная валюта профиля становится основной, отказ регистрации второй проекции не ломает первую.
- `test/locale.test.mjs` — zh-словарь совпадает с upstream, ru покрывает все ключи, неизвестные языки падают в en, отсчёт для zh/ru/en/ko, толерантная регистрация локалей, перевод однострочника пакета только для ru.
- `test/balance.test.mjs` — автовыбор валюты по пополненному кошельку, форматирование USD/CNY, смешанные кошельки, состояния `no-cny`/`failed`/`signed-out`.
- `test/balance-reconnect.test.mjs` — переподключение потока баланса: терминальное завершение, исключение в `$stream`, рост паузы, ручной `reconnect`, отмена попыток при `stop`/`dispose`.
- Остальные тесты — upstream (цены, проекции, совместимость, темы).
